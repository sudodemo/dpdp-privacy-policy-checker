# DPDP Privacy Policy Checker

Browser-only privacy-policy gap assessment for Indian DPDPA readiness.

## Features
- Company URL input with exact Privacy Policy URL recommendation.
- Paste-text fallback for CORS-blocked sites.
- No accounts, database, cookies, analytics, or localStorage.
- Rule-oriented checks for notice, rights, grievance, security, breach response, children, retention, processors, transfers and SDF readiness.
- English, Hindi and Marathi UI.
- Printable report: use the browser Print dialog and choose **Save as PDF**.
- Static-site architecture with no application secrets or server-side policy storage.

## Important limitation
A GitHub Pages/browser application cannot bypass a third-party website's CORS policy. Automatic URL retrieval therefore works only when the target permits browser access. The paste-policy-text path is the reliable fallback.

## Legal scope
This is a policy-language screening and gap assessment, not legal advice, an audit opinion, certification, or proof that operational controls exist. The assessment distinguishes policy evidence from actual implementation evidence.
